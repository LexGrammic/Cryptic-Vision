**Project:** Cryptic Vision

# Overview

Pocket Runtime Doctor is the first engineering instrument built on the Cryptic Vision platform.

It provides an observation-first environment for analyzing software systems, generating engineering reports, and assisting developers through governed AI orchestration.

Rather than modifying systems immediately, Pocket Runtime Doctor begins with observation, verification, and evidence before recommending engineering actions.
