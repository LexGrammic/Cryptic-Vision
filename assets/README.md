# Assets

The **Assets** directory contains visual resources and supporting media for the Cryptic Vision platform.

These assets support the engineering documentation and are derived from verified specifications.

---

# Purpose

This directory exists to keep visual resources organized and separate from engineering documentation.

Visual assets should only be created after their corresponding specifications have been reviewed and verified.

---

# Asset Categories

Current and planned assets include:

- Platform architecture diagrams
- Runtime architecture diagrams
- System flow diagrams
- Interface screenshots
- Engineering illustrations
- Icons
- Logos
- Presentation graphics

---

# Engineering Workflow

Visual assets follow the Occult Grammar Protocol (OGP).

```text
Concept

↓

Specification (.md)

↓

Verification

↓

Presentation (.png / .svg)
```

Documentation drives artwork.

Artwork should never become the source of truth.
